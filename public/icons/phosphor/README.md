# Phosphor icons

Official, unmodified Regular-weight SVGs from [Phosphor Core](https://github.com/phosphor-icons/core), pinned to commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e`.

Source: `https://github.com/phosphor-icons/core/tree/2b75f3ad12b420c9504ef05df8d2564a28f8500e/assets/regular`

Vendored `arrow-up-right.svg` and `caret-down.svg`.

Only used icons are vendored. CSS masks inherit the surrounding text color and let the browser cache each small SVG across usages. No icon font, JavaScript dependency, or CDN is required.

The same pack supplies `github-logo.svg`, `x-logo.svg`, and `linkedin-logo.svg`; add those from the pinned source when needed rather than shipping the entire pack.
